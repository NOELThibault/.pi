## This is my personnal configuration for the pi agent harness.

It is mainly a productivity tool and is not used to produce code.

# Features

- Interactive learning system with visuals
- PDF and YouTube video summary/analysis
- Web searches
- Prompt snippets
- Logs in .md files
- Bash guarding
- Interactive subagents

Plans for the future:
- Speech to text
- Todo system
- Translation skill
- Text to speech
